# Fonts Folder

Place your Bangla (Bengali) font files (.ttf or .otf) in this folder.

## Recommended Bangla Fonts

- **Kalpurush** - Popular for Bengali text
- **Siyam Rupali** - Clear and readable
- **SolaimanLipi** - Traditional Bengali font
- **AdorshoLipi** - Modern Bengali font
- **Mukti** - Free Bengali font

## Usage

After placing your font file here, update the font name in:
- `App.xaml` - Set the default font family
- Individual XAML files - Override font family as needed

The font will be automatically loaded when the application starts.
